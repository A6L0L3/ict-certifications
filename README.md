## 📖 分区说明

### 数通厂商认证（7 篇）

覆盖华为、思科、H3C、中兴、浪潮、迈普、锐捷七家，均以「初级 → 中级 → 专家」三级为主线，命令区分各自 CLI 体系（VRP / IOS / Comware / ZXR10 / INOS / RGOS 等）。内容重"可复制、可验证"：每个技术点配命令、配置片段与 show 输出对照，并标注所属认证层级。

- 华为 HCIA→HCIP→HCIE、思科 CCNA→CCNP→CCIE：主线最完整，覆盖交换、路由、安全、自动化与实验冲刺。
- H3C NE→SE→IE、中兴 ZCIA→ZCIP→ZCIE、浪潮 ICCA→ICCP→ICCE、迈普 MPNA→MPNP→MPIE、锐捷 RGSA→RGSP→RGSE：按各厂商考纲与产品线组织，含开局、二层、路由、安全、排障与项目交付。

### 软考（3 篇）

- **数据库系统工程师（中级）**：从三级模式、关系代数、SQL、事务并发到备份容灾与多平台部署。
- **网络工程师（中级）**：覆盖体系结构、交换路由、网络安全、广域网、运维排障与下午计算/配置题。
- **信息系统项目管理师（高级 / 高项）**：以十大管理、八大绩效域、案例计算与论文写作为核心，配冲刺模考与速记。

> 每篇均以"单文件"承载，板块0 为学习路径与导读，板块1~N 对应考纲模块；厂商篇偏"命令与配置"，软考篇偏"考点与题型"。

## 🧭 笔记体例

每篇笔记自足、格式统一，打开即用：

```
# 板块0 · 学习路径与备考总纲
## 0_1 小节
## 0_2 小节
# 板块1 · 主题
## 1_1 小节
```

- 板块0 承担「考什么 + 先学什么 + 怎么练 + 到哪算达标」的总控；
- 厂商篇按「原理 → 命令 → 配置 → 验证 → 排障 → 考点」六段式展开；软考篇按「考点 → 题型 → 模板 → 真题」组织；
- 每个板块末尾配速查表、自测清单或真题索引，便于回查与验证；
- 图示一律用 ASCII 字符画 / 表格 / 缩进文本，不依赖任何外链图片；时间以相对表述呈现，不写死年份。
